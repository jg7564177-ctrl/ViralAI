# Dossier de publication ViralAI

Ce dossier contient les éléments nécessaires à la préparation de la publication.

## Contenu

- SHORT_DESCRIPTION.md : description courte pour l’App Store / Google Play
- LONG_DESCRIPTION.md : description longue pour les fiches de publication
- metadata.json : version, build number et package name
- screenshots/ : dossier réservé aux captures d’écran

## Version actuelle

- nom : ViralAI
- package Android : com.viralai.app
- version : 1.0.0
- build : 1
- cible : application mobile WebView légère vers l’URL publique HTTPS de ViralAI

## Règles de publication

- Aucune génération vidéo réelle ne doit être déclenchée depuis l’APK
- Le backend reste responsable de l’IA, du chat, des comptes et des crédits
- Les paiements doivent rester désactivés tant qu’un fournisseur réel n’est pas branché
- URL publique HTTPS obligatoire
